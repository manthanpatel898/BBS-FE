# ZenBooking Public Homepage Redesign

## Purpose

Replace the banquet-only marketing page with a realistic, conversion-focused ZenBooking homepage that presents two separate solutions: Banquet Management and Event Decoration Management.

## Approved structure

1. Public navigation with Solutions, Features, How it works, Customer stories, Contact, Login, and Book a free demo.
2. Hero explaining the complete inquiry-to-event workflow without invented performance statistics.
3. Animated banquet operational preview and banquet lifecycle strip.
4. Interactive solution switcher for Banquet Management and Event Decoration Management.
5. Feature groups covering inquiries/follow-ups, menus/decoration planning, payments/documents, reports, users, and audit history.
6. Optional banquet-to-event-partner inquiry pipeline explanation.
7. Real-feedback section designed for customer-approved quotes only.
8. Mobile-first product section, final demo CTA, and updated footer.

## Content rules

- Do not publish fabricated customer counts, conversion rates, setup times, or conflict-reduction percentages.
- Testimonials must remain clearly marked placeholders until approved customer feedback is supplied.
- Describe only features currently supported by the platform.
- Keep Banquet and Event Decoration positioned as separate company workspaces.

## Motion rules

- Use entrance, scroll-reveal, tab-transition, workflow-progress, live-status, hover, and subtle floating animations.
- Banquet-specific motion represents inquiry capture, hall confirmation, menu planning, advance receipt, and event readiness.
- Motion must not block interaction and must honor `prefers-reduced-motion`.
- Avoid heavyweight animation dependencies so static export and mobile performance remain safe.

## Responsive and accessibility requirements

- Mobile-first layout with readable typography, full-width CTAs, stacked solution panels, and simplified workflow animation.
- Tablet and desktop layouts use available width without horizontal scrolling.
- All interactive controls remain keyboard-accessible and solution tabs expose selected state.
- Decorative animation is hidden from assistive technology.
